# Tech Stack & Hosting Strategy

## Defined Tech Stack

*   `language - Typescript`: I will program in typescript, a language that catches bugs early and makes the code easier to maintain. It is used for both front end and back end.

*   `Framework - Next.js`: I'll use Next.js to handle page routing, server-side rendering, and API routes, so the timer and logging forms live in one project without a separate server.

*   `Styling - Tailwind CSS`: I'll use Tailwind CSS for styling layout elements

## Hosting & Deployment Strategy

I'll host the app on Vercel, the company that created Next.js, so it can work with almost no configuration.

Vercel is connected directly to the GitHub repository.

The database and authentication run on Supabase, a separate managed service, so no server needs to be maintained.
